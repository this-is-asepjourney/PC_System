# PC-System Monitor

A comprehensive system resource monitor built with PySide6 and psutil.

## Features
- Real-time CPU, RAM, Disk, and Network monitoring
- Process management
- Hardware sensor monitoring
- Real-time graphing
- Alert system
- System tray support
- SQLite database for historical metrics

## Tech Stack
- **UI:** PySide6
- **System Metrics:** psutil
- **Realtime Graphs:** pyqtgraph
- **Database:** SQLite
- **Configuration:** PyYAML

## Quickstart

```bash
pip install -r requirements.txt
python app.py
```
